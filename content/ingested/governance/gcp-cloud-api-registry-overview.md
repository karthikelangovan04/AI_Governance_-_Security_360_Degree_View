# Cloud API Registry overview

**Google Cloud service:** [Cloud API Registry](https://docs.cloud.google.com/api-registry/docs/overview) — centralized catalog for discovering, governing, using, and monitoring Model Context Protocol (MCP) servers and tools.

**Preview.** Cloud API Registry helps agentic AI development by providing unified discovery, centralized governance, simplified integration, and broad support (Google services + your organization via Apigee API hub).

## Key benefits

- **Unified discovery** — find all available MCP servers and tools in one place
- **Centralized governance** — manage and control access to MCP servers and tools across your organization
- **Simplified integration** — discover and understand capabilities and connection details
- **Broad support** — integrate metadata from Google services or your organization via **Apigee API hub**

## Key concepts

- **Model Context Protocol (MCP)** — open, standardized protocol for connecting AI applications to external systems
- **MCP server** — endpoint that exposes functionalities known as MCP tools
- **MCP tool** — specific function or capability provided by an MCP server that an AI agent can invoke
- **Apigee API hub** — platform for managing your organization's APIs, including MCP servers and tools; Cloud API Registry imports metadata from Apigee API hub
- **Service Usage** — service that controls enabling/disabling MCP endpoints across resource hierarchy (projects, folders, organizations)

## Primary roles

- **Platform administrators** — manage the registry; enable/disable MCP servers for projects
- **Application developers** — use the registry to find and understand which MCP tools to use when building AI applications
