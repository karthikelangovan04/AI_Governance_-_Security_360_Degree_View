# Ingested Content (from URLs)

Place here markdown files created from URLs (one file per article/source). **Every file must include citation:** frontmatter (`source_url`, `source_title`, `ingested_date`, `topic`) and a Reference block at the end. See [content/CITATION_STANDARD.md](../CITATION_STANDARD.md).

Subfolders:
- `observe/` — Observability, logging, monitoring
- `authentication/` — Auth, identity, M2M
- `governance/` — Policies, frameworks, compliance

When you have a URL, ask: "Fetch this URL and save as markdown in content/ingested/<topic>/ **with citation** (frontmatter + reference block)."
